# 雨夜窗台 · Ambient Diorama

用 Three.js 搭建的白噪音“微缩生态”小组件：一个低多边形（Low-Poly）风格的赛博朋克雨夜窗台。
窗外是霓虹闪烁的城市，玻璃上的雨滴实时折射窗外的光，昼夜光影会自然流转。
点击房间里的物体，可以开关对应的立体声白噪音音轨，自由混音。
还能切换到「漫游模式」，操控一个低多边形小人在房间里走动（键盘鼠标或手机摇杆都行）。

**在线体验：<https://jalensuggs77.github.io/ambient-diorama/>**（戴上耳机效果最好；手机建议横屏）

```bash
npm install
npm run dev              # 开发，http://localhost:5173
npm run dev -- --host    # 同一 Wi-Fi 下用手机访问（终端会打印局域网地址）
npm run build            # 生产构建，输出到 dist/
npm run preview          # 本地预览构建结果
```

## 功能

| 物体 | 音轨 | 声音内容 |
| --- | --- | --- |
| 🌧️ 窗玻璃 | 雨声 / 风雪 | 粉噪雨幕 + 随机的玻璃雨点 / 窗台水滴；闪电后按距离延迟的雷声。雪夜换成呼啸的阵风 |
| 🔥 壁炉 | 壁炉 | 低沉的火焰呼吸 + 木柴爆裂的噼啪声（会同步喷出火星） |
| 📻 收音机 | 收音机 | 电台沙沙底噪 + 带磁带抖动的 lo-fi 和弦、鼓点（扬声器随节拍跳动） |
| 🎐 风铃 | 风铃 | 按阵风强度敲响的五音铜管（非谐波泛音 + 拍频，铜管会同步摆动） |
| 🐈 猫 | 猫咪呼噜 | 约 25Hz 脉冲调幅的呼噜声，吸气/呼气与猫的胸口起伏同步；点它时会伸个懒腰再睡回去 |

- **所有声音都是 Web Audio 实时合成的**，仓库里没有任何音频文件。
- **后台也不断档**：雨点、火星、风铃、鼓点这些零散的声音由一个 AudioWorklet 时钟驱动调度（音频线程每 50ms 发一次消息），
  不依赖会被后台节流的 `setInterval`；标签页隐藏时还会把提前安排的时间从 0.25 秒拉长到 1.5 秒，主线程卡顿也不会出现空档。
- **立体声空间化**：每条音轨挂在 `PannerNode` 上，位置就是物体在场景里的位置，听者跟随相机。
  壁炉在左、猫在右、风铃在窗前，移动视角时声像也会随之变化。另有一个共享的卷积混响模拟房间声场。
- **昼夜交替**：太阳和月亮沿窗外的弧线运动，天空颜色、云层、星星、城市灯光和霓虹强度都随时间变化。
  阳光/月光是一个投射阴影的平行光，只能从窗洞照进来，所以地板上会出现带窗框阴影的光斑。
  窗户本身还是一块面光源（RectAreaLight），白天是天光，夜里是霓虹辉光。台灯会在天黑后自动亮起。
- **雨滴折射 Shader**（`src/shaders/rainGlass.js`）：
  - 窗外场景先渲染到带 mipmap 的 HDR 离屏纹理；
  - 水珠被当作凸透镜，反向偏移采样坐标，于是每颗水珠里都有一个缩小、倒置的窗外世界；
  - 没有水珠的地方是起雾的玻璃，用高层 mip + 多点旋转采样做模糊；
  - 两层“撞击后慢慢蒸发”的静止水珠 + 两层走走停停滑落的水珠，滑落的水珠会留下清晰的轨迹和残留小水滴；
  - 在玻璃上拖动鼠标/手指可以擦掉雾气，雾气会慢慢重新凝结。
- **闪电**：雨量大于一半时随机出现，照亮天空、云层和楼群，并从窗户打进一道冷光，随后传来雷声。
- **雪夜模式**：面板里把天气切到「雪夜」，窗外飘雪、楼顶积雪，玻璃边角和窗棂旁结出带闪光的冰花，玻璃上粘着慢慢融化的雪花，
  “雨声”变成风雪声，也不再打雷。雨雪之间是平滑过渡的。
- **夜里玻璃映出室内**：窗玻璃同时是一面 `Reflector`，用半分辨率的镜像相机渲染室内；窗外越暗倒影越明显，
  倒影会被水珠扭曲、被雾和霜冲淡。漫游时还能在玻璃里看到自己。白天自动跳过这次渲染。
- **白天的光柱和浮尘**（`src/scene/sunbeams.js`）：沿视线做光线步进，把采样点沿阳光方向投影回窗洞，算出带窗棂影子的体积光；
  几百颗浮尘只在光柱里亮起来。
- **小细节**：茶壶、茶杯和马克杯冒热气；雨大时窗户底部积起一道水，水面起伏并朝一侧流走，上方有水流淌下来汇入。
- **房间灯**：按 `L`、点面板里的「开灯」，或在漫游时走到门边按墙上的开关，吸顶灯会闪两下再亮起，吊灯一起变亮。

## 漫游模式

点左下角的「🚶 漫游模式」，就能操控一个戴耳机的低多边形小人在整个房间里走动：
窗边、壁炉、床、书桌、书架和房门都可以走过去看看。音源是空间化的，走近壁炉火声会变大，转身声像也会跟着变。

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `Shift` | 奔跑 |
| `空格` | 跳 |
| 鼠标 | 环顾四周（会锁定指针；不支持锁定时改为拖动） |
| 滚轮 | 第三人称下拉远 / 拉近镜头 |
| `V` | 切换第一人称 / 第三人称 |
| `E` / 左键 | 开关准星对准的音源 |
| `F` | 在电脑椅、床边、窗边坐垫坐下 / 站起来 |
| `L` | 开关房间灯（门边墙上也有开关，对准按 `E`） |
| `Esc` | 暂停（可调混音面板或退出漫游） |

小人的骨架由嵌套的 Group 组成，走、跑、跳、坐、眨眼都是程序化动画；第三人称镜头会被墙和大件家具挡住时自动拉近。

### 手机上

| 操作 | 作用 |
| --- | --- |
| 左下角摇杆 | 移动：手指按在左下区域哪里，摇杆就出现在哪里；轻推慢走，推到底就跑（摇杆边框变粉） |
| 在屏幕其他地方拖动 | 环顾四周 |

| ⤒ | 跳 |
| ✋ | 开关准星对准的音源或电灯开关（对准时按钮会亮起）；直接轻点画面也行 |
| 🪑 | 坐下 / 站起来（附近有座位时亮起） |
| 🎥 | 切换第一 / 第三人称 |
| 💡 | 开关房间灯 |
| ⏸ | 暂停（可调混音面板或退出漫游） |

横屏体验更好（竖屏时会自动加大视野并提示）。界面适配了刘海 / 灵动岛和底部横条的安全区域；
iOS 17 以上的 Safari 会把音频声明为“播放”类型，静音开关打开时也能出声。

## 操作

- 点击场景中的物体：开关对应音轨（悬停有提示）
- 拖动玻璃：擦掉雾气
- 移动鼠标：视差；滚轮：缩放；触屏：左右拖动平移视角
- `L`：开关房间灯
- 右侧面板：各音轨音量、预设（专注 / 入眠 / 雨夜电台 / 晴日微风）、时间、时间流速
  （可选“跟随本地时间”）、天气（雨夜 / 雪夜）、雨量或雪量、起雾程度、灯光、总音量。设置会保存在浏览器本地。

## 作为小组件嵌入

加上 `?widget` 参数时面板默认收起，适合放进 iframe：

```html
<iframe src="https://jalensuggs77.github.io/ambient-diorama/?widget" width="420" height="420" style="border:0;border-radius:16px" allow="autoplay"></iframe>
```

其他 URL 参数：`?t=21.5`（初始时间，小时）、`?rain=0.8`（初始雨量）、`?debug=outside`（只看窗外场景）。

## 部署

推送到默认分支后，GitHub Actions（`.github/workflows/deploy.yml`）会自动 `npm ci && npm run build`，
把 `dist/` 发布到 GitHub Pages。也可以在仓库的 Actions 页面手动运行 “Deploy to GitHub Pages”。

`vite.config.js` 里用的是相对路径 `base: './'`，所以同一份构建放在 Pages 的子路径、任意域名根目录或 iframe 里都能用。

> 局域网的 `http://192.168.x.x` 地址不是安全上下文，浏览器不会开放 AudioWorklet，后台播放会退回到普通定时器，
> 切到后台后零散的声音可能断续；通过 HTTPS（比如 GitHub Pages）访问就没有这个问题。

## 代码结构

```
vite.config.js         构建配置（相对路径 base）
.github/workflows/     GitHub Pages 自动部署
src/
  main.js              渲染循环、相机、指针交互、状态与本地存储
  dayNight.js          昼夜计算：太阳/月亮方向、天空与光照颜色
  tracks.js            音轨、预设、时间流速定义
  ui.js / style.css    混音面板
  scene/outdoor.js     窗外：天空、实例化楼群、霓虹招牌、飞行汽车、雨丝 / 雪花
  scene/sunbeams.js    白天透过落地窗的体积光柱与浮尘
  scene/room.js        室内：房间、窗户、壁炉、收音机、风铃、猫、床、书桌、书架，以及各自的动画和碰撞体
  explore/character.js 漫游小人：低多边形模型 + 程序化骨骼动画
  explore/explorer.js  漫游模式：键盘移动、碰撞、跳跃、坐下、第一/第三人称相机、HUD
  explore/touchControls.js 手机上的虚拟摇杆与动作按钮
  shaders/rainGlass.js 雨滴折射玻璃（含室内倒影、窗底积水、结霜）
  shaders/sky.js       天空穹顶（渐变、日月、星空、云、闪电）
  shaders/city.js      程序化窗户、霓虹边线、雾
  shaders/rainStreaks.js GPU 驱动的雨丝
  shaders/snowfall.js  GPU 驱动的雪花
  audio/engine.js      程序化音频引擎与五条音轨
```
